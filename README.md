# متجر اتقان — دليل التشغيل

## 1) إعداد قاعدة البيانات (مرة واحدة)
في لوحة Supabase → SQL Editor، نفّذ الملفات بهذا الترتيب:
1. `schema.sql`
2. `functions.sql`
3. (اختياري للاختبار) `seed_sample.sql`

## 2) إنشاء أول مستخدم إداري
1. من Supabase → Authentication → أضف مستخدمًا (بريد/كلمة مرور) لموظف اتقان.
2. من SQL Editor نفّذ:
   ```sql
   insert into admin_users (id, full_name, role)
   values ('UUID-المستخدم-من-Authentication', 'اسم الموظف', 'admin');
   ```

## 3) رفع ملفات المنتجات
من Storage:
- `product-files` (خاص) → ملف الدراسة الكامل PDF لكل منتج.
- `product-samples` (عام) → عينة من الدراسة.
- `product-covers` (عام) → صورة الغلاف.
انسخ المسار (path) وضعه في حقول `study_file_path` / `sample_file_path` / `cover_image_path` عند إضافة المنتج.

## 4) بيانات الحساب البنكي
عدّل `config.js` وضع اسم البنك، اسم الحساب، والآيبان الفعلي لاتقان.

## 5) رفع الموقع
الملفات (`index.html`, `styles.css`, `app.js`, `config.js`) مستقلة بالكامل — ارفعها إلى استضافة الموقع
(مثل Vercel أو Netlify أو أي استضافة ثابتة) واربطها بالنطاق `store.itqanbs.sa`.

## 6) البريد الإلكتروني التلقائي (Resend)
تم بناء دالة الإرسال (`supabase/functions/send-order-email/index.ts`) وربطها بالموقع ولوحة التحكم بالكامل.
حاليًا تعمل الدالة لكن **بدون إرسال فعلي** لأن مفتاح Resend غير مضاف بعد — لن يتعطل الموقع، فقط لن تُرسل الرسائل.

### أ) رفع الدالة (مرة واحدة)
1. من لوحة Supabase → **Edge Functions** → **Create a new function**.
2. سمّها بالضبط: `send-order-email`.
3. افتح الدالة اللي أنشأتها، احذف الكود الافتراضي، والصق محتوى ملف
   `supabase/functions/send-order-email/index.ts` كاملاً.
4. اضغط **Deploy**.

### ب) لاحقًا — عند تجهيز حساب Resend
1. أنشئ حساب على resend.com وفعّل نطاقكم (`itqanbs.sa`) حسب تعليماتهم (سجلات DNS).
2. خذ الـ API Key من Resend.
3. في Supabase → **Edge Functions** → **Manage secrets**، أضف:
   - `RESEND_API_KEY` = المفتاح من Resend
   - `RESEND_FROM` = مثل `اتقان <store@itqanbs.sa>` (بعد تفعيل النطاق في Resend)
4. من هذه اللحظة، كل الرسائل (تأكيد الطلب، اعتماد السداد، رفض الإثبات، تسليم الدراسة) تُرسل تلقائيًا — بدون أي تعديل إضافي بالكود.

## 7) واتساب
رقم الدعم مضاف بالفعل في `config.js` (0569051686) وزر واتساب عائم يظهر بأسفل يسار الموقع.

## ما تم بناؤه
- الموقع الكامل + لوحة التحكم + قاعدة البيانات (كما بالأعلى).
- إرسال بريد تلقائي لكل حدث في الطلب (جاهز، بانتظار مفتاح Resend فقط).
- زر واتساب للدعم.

## المتبقي
- تفعيل حساب Resend وإضافة المفتاح (خطوة "ب" أعلاه) — بعدها المتجر مكتمل بالكامل حسب خطة المرحلة الأولى.
- إضافة 5–10 دراسات فعلية بدل البيانات التجريبية.
