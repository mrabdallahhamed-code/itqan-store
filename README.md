# منصة اتقان للخدمات الاستشارية — دليل التحديث (المرحلة الثانية)

## الترتيب المهم (لا تغيّره)
1. Supabase → SQL Editor: نفّذ `migration-phase2.sql` كاملاً مرة واحدة.
2. Supabase → Edge Functions → `send-order-email`: استبدل الكود بمحتوى `index.ts` الجديد ثم Deploy.
3. Supabase → Edge Functions → Manage secrets: أضف `NOTIFY_EMAIL` = بريد فريق اتقان الذي تريد أن تصله تنبيهات الطلبات الجديدة.
4. GitHub Desktop: انسخ ملفات الزيب فوق ملفات المستودع (بدون حذف config.js) ثم Commit و Push.

## ملاحظات
- ملف `config.js` لم يُدرج في الزيب عمدًا حتى لا يمسح بيانات الحساب البنكي التي عدّلتها. لا تغيّره.
- ملف `site-settings.js` (جديد): أضف فيه رابط ووصف منصتي صمام ومبتدأ لتظهر في الصفحة الرئيسية.
  المنصة لا تظهر إلا إذا وُضع لها رابط.
- لتتبع مصدر العملاء القادمين من منصة أخرى: ضع فيها رابطًا لهذا الموقع بهذا الشكل
  `https://store.itqanbs.sa/?src=samam` وسيظهر "samam" في عمود المصدر داخل لوحة التحكم.
- محتوى الخدمات والباقات مسودة مبدئية؛ عدّلها من لوحة التحكم (الخدمات / الباقات) دون الرجوع للكود.
- مسار الشراء القديم (الدراسات الجاهزة) تم إيقافه. الجداول القديمة لم تُحذف، ولا تؤثر.

## مسار الطلب الجديد
طلب الخدمة ← تواصل الفريق ← عرض السعر ← موافقة العميل ← تحويل وإثبات ← اعتماد ← تنفيذ ← تسليم
كل مرحلة يصلها بريد تلقائي للعميل، والتنبيهات المهمة تصل لفريق اتقان.
